
# ANOVA-анализ: сравнение эффективности видов терапии

Этот проект демонстрирует применение однофакторного дисперсионного анализа (ANOVA) для оценки различий в эффективности четырёх типов терапии (A, B, C, D) на основе данных экспрессии генов.

## 📊 Описание

Данные содержат значения экспрессии (`expr`) по группам терапии. Мы проводим ANOVA-анализ, чтобы проверить, есть ли статистически значимые различия между средними значениями в этих группах.

## 📁 Данные

Файл: [`genetherapy.csv`](genetherapy.csv)

Структура:

* `Therapy`: тип терапии (`A`, `B`, `C`, `D`)
* `expr`: уровень экспрессии

## ⚙️ Методы

В анализе реализовано:

* Расчёт общей средней (grand mean)
* Оценка межгрупповой (SSB) и внутригрупповой (SSW) дисперсии
* Расчёт F-статистики и её сравнение с критическим значением
* Визуализация F-распределения и боксплота (boxplot)
* Вычисление 95% доверительных интервалов для средних по группам

## 📌 Результаты

| Показатель   | Значение |
| ------------ | -------- |
| Grand Mean   | 96.3     |
| SST          | 37.3     |
| SSB          | 560.7    |
| SSW          | 1302.3   |
| df (всего)   | 56       |
| F-статистика | 8.035    |
| P-значение   | 0.00015  |

### Доверительные интервалы для средних значений:

| Группа | Среднее | 95% CI (низ) | 95% CI (верх) |
| ------ | ------- | ------------ | ------------- |
| A      | 99.73   | 97.63        | 101.84        |
| B      | 98.80   | 95.82        | 101.78        |
